# TicketBox

TicketBox is a concert ticket booking platform designed for large-scale music events in Vietnam.

The system helps audiences purchase tickets online, receive QR-based e-tickets, and check in at concert venues. It also supports organizers in managing concerts, ticket inventory, revenue tracking, and audience flow.

This project focuses on solving common problems in modern ticketing systems such as:

- website overload during ticket opening
- ticket overselling
- unstable payment processing
- offline ticket check-in
- anti-spam and anti-bot protection
- scalable system architecture

---

# Main Features

## Audience

- Browse upcoming concerts
- View concert details and seating areas
- Purchase tickets online
- Receive QR e-tickets
- Receive notifications and reminders

## Organizer

- Create and manage concerts
- Configure ticket types and prices
- Track ticket sales and revenue
- Upload artist information for AI-generated summaries

## Check-in Staff

- Scan QR tickets using mobile devices
- Validate tickets at entrance gates
- Support offline check-in when internet is unstable

# Project Goals

The project aims to:

- support large traffic during ticket sales
- ensure fair ticket purchasing
- prevent duplicate payments
- provide reliable ticket validation
- design a scalable and maintainable system

---

# System Challenges

Some important challenges addressed in this project include:

- Thousands of users purchasing tickets at the same time
- Preventing multiple users from receiving the same ticket
- Handling payment gateway failures
- Supporting offline check-in at crowded venues
- Reducing database overload during peak traffic
