# TicketBox Product Context

register: product

## Product Summary
TicketBox is a premium Vietnamese concert ticketing platform for high-demand events. The customer web app must handle discovery, purchase, and ticket access with a cinematic yet trustworthy experience.

## Primary Users
- Audience: browse events, buy tickets, manage e-tickets, check in
- Organizers: configure events and ticket tiers, monitor sales
- Gate staff: verify tickets via mobile check-in

## Goals
- Fair, fast ticket purchase under peak demand
- Clear seat selection and ticket tier guidance
- Reliable ticket access and check-in readiness

## Tone
- Cinematic, premium, modern
- Emotional and event-focused, but still task clear
- Confident, not flashy

## Anti-Goals
- Generic admin templates
- Bootstrap aesthetics
- Cluttered layouts or noisy gradients
- Inconsistent spacing or color usage

## Content Language
- Vietnamese-first UI copy

## Platforms
- Customer web app (this scope)
- Admin web and mobile check-in (out of scope here)
